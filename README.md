## yes, another chess app

---

## features

* play chess locally
* two board modes
* analysis board
* works offline after load
* clean minimalistic ui

---

## stack

* react
* typescript
* vite

---

## installation

```bash
git clone https://github.com/jasurlive/chess.git
cd chess
npm install
npm run dev
```
